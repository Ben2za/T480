# Host Audit

Date: 2026-05-26

## Scope

This audit is an orientation snapshot for future repo work.

Read:

- Repo context and tracked files.
- Host filesystem metadata and selected non-secret configuration.
- Key installed package versions for the planned operator stack.
- User desktop, shell, CTOS tree, firewall, package manager, boot, and libvirt metadata.

Not read:

- Private keys, tokens, browser state, Codex auth contents, shell history contents, logs, VM disk contents, loot, private reports, and generated sensitive artifacts.
- Full package database contents. Only selected stack packages and cache size/metadata were inspected.

Sandbox limits:

- `systemctl`, `hostnamectl`, `virsh`, `ip`, `ss`, `bootctl`, and `sudo` runtime checks are restricted from this Codex sandbox by system bus, netlink, libvirt socket, EFI, or no-new-privileges limits.
- Mount ownership and read-only flags seen from inside the sandbox may not reflect the real host namespace.
